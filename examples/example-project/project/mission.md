# Mission — nightowl

> The anchor. **Everything in this project traces back here** (`mission_link`).
> If an artifact can't say why it serves this mission, that's a scope-check signal.

## Mission
Build a small, self-hosted CLI that reads my RSS feeds and delivers one
overnight digest email each morning — so I stop grazing feeds all day.

## Vision
One email at 7am with everything worth reading. No apps, no feeds tab, no
doomscrolling. Runs unattended on cheap hosting for years.

## Value proposition
Sole user: me. Value is attention recovered (~30 min/day) and information kept.

## Principles
- Boring technology, run for years without maintenance.
- Local-first data; hosting is only for scheduling and email.
- If it needs a dashboard, it's too complicated.

## Constraints
- **Budget:** < $5/month total.
- **Timeline:** working digest by 2026-12-01.
- **Compliance / regulatory:** none.
- **Technical / material:** runs on a single small VPS or free tier; Python.
- **Team:** solo + AI.

## Non-goals
- No web UI, no multi-user, no filtering/ranking "AI", no mobile app.

software — chosen at onboarding
